# Honda SH300i ABS — Manuale d'Uso e Manutenzione

Benvenuto nel manuale d'uso e manutenzione interattivo e premium per lo scooter **Honda SH300i ABS**. Questo progetto digitalizza le informazioni di servizio, rendendole facilmente consultabili e ricercabili direttamente da qualsiasi browser web.

---

## 🌟 Caratteristiche Principali
* **Design Premium & Reattivo:** Interfaccia ispirata al mondo editoriale, ottimizzata per display Desktop, Tablet e Mobile.
* **Manuale Integrato:** Include i manuali ufficiali in PDF (`SH300.pdf` e `SH300i ABS.pdf`) e le singole pagine digitalizzate in alta qualità.
* **Sistema di Ricerca Rapida:** Ricerca instantanea tra le sezioni del manuale.
* **Schede di Manutenzione Interattive:** Tabelle e griglie dettagliate per la manutenzione periodica dello scooter.

---

## 🛠️ Come Installare (Installation)

### Prerequisiti
* Qualsiasi browser web moderno (Chrome, Firefox, Safari, Edge).

### Installazione Locale
1. Clona la repository sul tuo computer locale:
   ```bash
   git clone https://github.com/mich-de/hondash300.git
   cd hondash300
   ```

---

## 🚀 Come Usare (How to Use)

### Visualizzazione del Manuale
* È sufficiente fare doppio clic sul file `index.html` per aprire l'interfaccia interattiva nel browser preferito. Non è necessario alcun server web dedicato.
* Utilizza la barra di ricerca in alto per trovare velocemente argomenti specifici.
* Naviga tra i capitoli usando la comoda barra laterale a sinistra.
